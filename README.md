# Prompts Instagram — @vitor.menoli

Repositório com os prompts de IA usados nos carrosséis "post por prompt" do meu Instagram [@vitor.menoli](https://instagram.com/vitor.menoli).

## Como funciona

Toda terça e domingo eu posto um carrossel no Instagram testando um prompt de imagem diferente. No final da legenda de cada post tem uma palavra-chave (ex: `CEO`, `ANIME`). Basta comentar **"PROMPT"** no post que eu te mando no direct o link pra buscar o prompt completo pela palavra-chave correspondente.

## Estrutura

Cada prompt fica em um arquivo `.txt` na raiz deste repositório, nomeado com a palavra-chave do post (em maiúsculo_.

O conteúdo de cada arquivo é o texto completo do prompt usado naquele post.

## Buscar um prompt

A forma mais fácil de encontrar o prompt que você procura é pela página de busca no meu site: **vitormenoli.com/prompts** - digite a palavra-chave do post e o prompt aparece na hora, com botão de copiar.

Se preferir, também dá pra navegar direto pelos arquivos aqui no repositório.
